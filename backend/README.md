# HPDQ Quiz API
Backend Express + Firebase Admin SDK.
Required environment variables:
- FIREBASE_SERVICE_ACCOUNT_BASE64: base64 encoded service-account JSON
- FIREBASE_DATABASE_URL: https://hpdq-quiz-default-rtdb.asia-southeast1.firebasedatabase.app
- ADMIN_USERNAME: admin
- ADMIN_PASSWORD: set a strong secret
- ALLOWED_ORIGINS: https://hpdq-quiz.onrender.com
